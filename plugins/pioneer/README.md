# Pioneer plugin

Agent Plugins v1 clients, Codex, and Claude Code load the plugin from this directory. The root [`plugin.json`](plugin.json) and both client-specific manifests point to the same `pioneer` skill. The package contains no provider credentials or Pioneer executable.

Install the Pioneer CLI and configure Pi first. The [agent-integration guide](https://github.com/rock3r/pioneer/blob/main/user-guide/plugins.md) lists installation and validation steps.
